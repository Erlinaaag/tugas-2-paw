# Tugas 2 Pengembangan Aplikasi Web (PAW)
Pembuatan website Studium General ITERA menggunakan HTML5 semantik. Website terdiri dari halaman beranda, halaman berita, navigasi antarhalaman, tabel jadwal kegiatan, serta dokumentasi validasi HTML.

# Studium General ITERA

Website sederhana bertema Studium General ITERA yang dibuat untuk memenuhi tugas 2 Pengembangan Aplikasi Web (PAW).

## Fitur
- Halaman Beranda (index.html)
- Halaman Berita (berita.html)
- Struktur HTML5 Semantik
- Tabel Jadwal Kegiatan
- Navigasi Antar Halaman
- Logo ITERA
